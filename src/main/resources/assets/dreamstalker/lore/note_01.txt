read me

if you found this, you have already been dreaming.
i am writing it down because i stopped trusting my memory around the fourth night.

every time i sleep, i wake up exactly five minutes later in the same bed.
the dream is never the same place twice, but it is always built out of ordinary things.
trees. gravel. stone. nothing that should scare anyone.

that is how i knew something was wrong.
it does not need a monster's world. it only needs somewhere quiet to stand and watch.

- M.
